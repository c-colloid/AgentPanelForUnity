# エージェントの導入とサインイン

[操作ガイド](../../USER-GUIDE.md) > エージェントの導入とサインイン

パネルは既定の **Claude Code** のほか、ACP(Agent Client Protocol)対応の CLI にも切り替えて使えます。エージェントの切り替え・CLI の導入・サインインは、どれも 設定(ヘッダーの ⚙)> **接続** > **エージェント** カードで行います。

## エージェント別の手順

| エージェント | サインインに使うもの | API キーで使う場合 | 手順 |
|---|---|---|---|
| **Claude Code**(既定) | Claude のサブスクリプション(推奨) | 環境変数 `ANTHROPIC_API_KEY` | [Claude Code のサインイン](claude-code.md) |
| **Codex** | ChatGPT アカウント(推奨) | 環境変数 `CODEX_API_KEY` または `OPENAI_API_KEY` | [Codex のサインイン](codex.md) |
| **Grok Build** | SuperGrok / X Premium+ のアカウント(推奨) | 環境変数 `XAI_API_KEY` | [Grok Build のサインイン](grok-build.md) |
| **Gemini CLI** | Gemini Code Assist Standard / Enterprise | `GEMINI_API_KEY` または `~/.gemini/.env` | [Gemini CLI の設定](gemini-cli.md) |
| **その他の ACP 対応 CLI**(Qwen Code、Kimi CLI など) | CLI ごとの方法 | CLI ごとの方法 | [その他の ACP エージェント](custom-acp.md) |

## 切り替えの流れ(共通)

1. 設定 > 接続 > エージェント の **「エージェント」** で使うエージェントを選びます(v0.55.1 までは設定 > CLI にありました)。選んだエージェントは次の接続から使われます。
2. CLI が入っていなければ、同じカードに出る **「インストール」** を押します(npm で入るものは Node.js が必要です。実行するコマンドは押す前に表示されます)。
3. サインインが必要なら **「ログイン」**(Claude Code)/ **「サインイン」**(その他)を押し、ブラウザで認証します。完了するとパネルが再接続し、実際に使われた方式がカードに表示されます。

カードの状態は次の 4 つのどれかです。見出し右端の状態ピル(「サインイン済み」など)でも分かります。

| 状態 | カードの表示 | できること |
|---|---|---|
| 未サインイン | 「未接続。」と、サインインの案内 | 「サインイン」でログインコマンドを開始 |
| サインイン中 | 「ブラウザでの … へのサインインを待っています...」、サインイン URL と CLI の出力 | 「ブラウザで開く」「コピー」「キャンセル」 |
| 接続中 | 「… に接続しています...」 | 待つ |
| 接続済み | 「… に接続済み。」と、使われたサインイン方式 | 「アカウントを切り替え」 |

## API キーについて

- API キーはパネルには保存しません。OS の環境変数か、各 CLI 自身の設定ファイルに置いてください。
- OS の環境変数はエディタ(Unity Hub から起動している場合は Unity Hub も)を再起動しないと反映されません。

## エージェントによる違い

権限カード・チップと添付・Unity 操作ツール・スクリプト検証ゲート・思考ブロック・履歴ブラウザ・パネル内ログイン・サブエージェントのモデル設定は、どのエージェントでも同じように使えます。違いは次の 3 点です。

- **履歴**: ACP エージェントの会話はパネル自身が `UserSettings/AgentPanel/Sessions/` に保存し、Claude Code のセッションと同じ一覧に(エージェント名付きで)並びます。`session/load` に対応していないエージェントは再開時に新しいセッションを開始し、次のメッセージと一緒にそれまでの会話ログを受け取ります(会話欄にその旨のノートが出ます)。
- **サブエージェントのモデル設定**: 「サブエージェントモデルを強制固定」と「タイプ別の詳細設定」は、新しいセッションの最初に指示文として送られます(Claude Code のように環境変数や `.claude/agents` では渡せないため)。エージェントがサブエージェントのモデルを選べる場合にそれに従います。
- **スクリプト検証ゲートのフック**(`PreToolUse` フック)は Claude Code 専用です。ACP ではパネル側の `uap_scripts_commit` ゲートだけが働きます。

使えるモデルは CLI・認証方式・アカウントによって異なり、ヘッダーのモデルピッカーで選びます([モデルの選択](../sessions-and-models.md#モデルの選択))。各エージェントの実際の使用例は [エージェント別の使用例](../../AGENT-SHOWCASE.md) にあります。
