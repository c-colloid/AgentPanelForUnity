# スケッチの高機能化: 形(直線・折れ線・矩形・楕円)、描画中の視点操作、エリア分け(名前つきの閉じた領域)

日付: 2026-10-09 / 対象: `jp.colloid.unity-agent-panel`(Core v0.61.0-beta.6)
関連: `2026-09-17-scene-sketch-strokes.md`(スケッチの土台。本ノートはその拡張)、
`2026-09-18-agent-tools-overlay.md`(Scene ビューのツールバー)
状態: **実装済み**。Scene ビュー上の入力と描画は実機確認が必要(§7)。

## 1. 動機

ユーザーからの指摘 3 点。

1. **フリーハンドでしか描けない。** 「この矩形の範囲」「ここからここまで真っすぐ」を手ぶれした線で
   渡すのは精度も伝達力も落ちる。Shift の直線はあったが、矩形・楕円・角のはっきりした折れ線がない。
2. **描いている途中で画面の拡大・縮小・移動ができない。** 平面モードはホイールを深度に奪っていたので
   ズームできず、1 本のドラッグの間は視点を動かせない。大きな範囲を 1 筆で囲めない。
3. **既にあるワールドのエリア分けのような需要がある。** 「ここが広場、ここがスポーン、ここが森」と
   地面を区切って名前を付け、「広場にベンチを 4 つ」「森のエリアの木を増やして」と言いたい。
   エージェント側には「どのオブジェクトがどのエリアに入っているか」も要る。

## 2. 決めたこと

| # | 決定 | 根拠 |
|---|---|---|
| T1 | **形(`SceneStrokeShape`)を 5 つ**: フリーハンド / 直線 / 折れ線 / 矩形 / 楕円。保存形は従来どおりポリライン(`Points`)で、`Shape` を 1 つ足すだけ。矩形は 4 隅、楕円は 48 点、直線は 2 点、折れ線は置いた頂点そのまま。**形は Douglas-Peucker を通さない**(フリーハンドだけ間引く)。矩形・楕円は常に閉じる。表面モードの形は、辺を分割して(外周を 64 分割、256 点上限)1 点ずつ形の平面の法線方向から表面へ**レイキャストで落とす(ドレープ)**。当たらない点は平面上に残す | ポリラインのままなので `uap_stroke_list` の読み手(エージェント、Pro のメッシュツール)は何も変えずに使える。`shape` を見れば「4 点は矢印の隅」と分かる。表面モードで矩形を描いて辺が地形にめり込むのを避けるにはドレープが要る |
| T2 | **ホイールは Scene ビューのズームに返す。** 深度は **Ctrl(Cmd)+ホイール** と `[` `]`。右 / 中ドラッグと Alt は消費しない。**折れ線はクリックで頂点を置く**ので、クリックの合間に自由に視点を動かせる(カメラ正対平面は最初のクリック時に固定、S3 と同じ)。Esc は描画中なら線だけ破棄、もう一度でモード終了 | 「描いている途中で動かしたい」の本体は 1 筆のドラッグでは解けない(ボタンを離せば確定)。クリック式の折れ線を足すのが最小の解。深度操作を修飾キーに移すのは既存ユーザーの操作が変わるが、ズームが使えないほうが日常的に困る |
| T3 | 形の **平面内の基底**は、平面の法線と「カメラの右」から作る(`PlaneBasis`)。矩形の辺は画面の横に沿う。Shift で正方形 / 円 | 画面に沿った矩形が直感に合う。軸平面(X/Y/Z)でも同じ式で、カメラの右が法線と平行なら世界軸に退避 |
| T4 | **閉じた線 = 領域(`IsRegion`)**。ストロークに **`Name`** を持たせ、Scene ビューの S ラベル(クリックで名前ウィンドウ)、チップの右クリック「名前...」、スケッチ中の **N**(最新の 1 本)で付ける。名前はチップのラベル(「スケッチ S1: 広場」)、ペイロードの `name:` 行、`uap_stroke_list` の `name` に出る。領域には **面積**(`PolygonArea`、Newell の面積ベクトルの半分)と **重心**、そして **`contains`**(内包オブジェクト)を `uap_stroke_list` が付ける。内包判定は Renderer の bounds 中心を領域の平面に投影して多角形内判定(偶奇)。**床を除く**: 投影した足跡が外形全体を覆うオブジェクト(=その上に描いた地面)と、描いた対象(`HitPaths`)は内容物とみなさない。`contents:false` で歩かない、`max_objects`(既定 32)で名前の数を抑える(件数は常に正確) | エリア分けに必要なのは「名前」「どこ」「何が入っているか」。面積と重心は「広場の中央に」「10 m² あたり 1 本」の計算材料。床の除外がないと、地面の Plane 1 枚が全エリアの中身になる。平面の取り方は平面ストロークなら自分の平面、表面ストロークなら点列の Newell 法線(退避: サンプル法線の平均 → 上)で、斜面に描いても面積が出る |
| T5 | 領域は **半透明で塗る**(頂点色、α 0.18、`Hidden/Internal-Colored`、Transparent キュー、zTest Always、両面)。線の色は S 番号で **8 色を巡回**(S1 は従来の黄)。ラベルは領域なら重心、線なら始点 | 隣り合うエリアが見分けられないと分けた意味がない。塗りは `Graphics.DrawMesh` パスに載せたので撮影(`uap_editor_screenshot` の camera モード)にも映る。耳切り三角形分割(`Triangulate`、凹多角形可、穴なし)は Core に純関数で置き、自己交差でも例外にせず「何か塗る」にとどめる |
| T6 | 形の切替は Scene ビューのツールバー「Agent Tools」に**ドロップダウン**を 1 つ足す(現在の形の名前を表示)。キーは **1〜5**。コンテキストバーの「スケッチ」メニューに「形/」サブメニュー。形はモードとアーム状態をまたいで保持 | トグルを 5 つ増やすと帯が長すぎる。ドロップダウン 1 つで済む |

## 4. 操作

| 状況 | 操作 | 意味 |
|---|---|---|
| どちらのモードも | 1 / 2 / 3 / 4 / 5 | フリーハンド / 直線 / 折れ線 / 矩形 / 楕円 |
| | ホイール、右 / 中ドラッグ、Alt+ドラッグ | Scene ビューの視点操作(そのまま使える) |
| | N | 最新のスケッチに名前を付ける |
| | S ラベルをクリック / チップ右クリック「名前...」 | そのスケッチに名前を付ける |
| | Esc | 描画中なら破棄、そうでなければモード終了 |
| フリーハンド / 直線 | 左ドラッグ(Shift で直線) | 1 本描く |
| 矩形 / 楕円 | 隅から隅へ左ドラッグ(Shift で正方形 / 円) | 閉じた形を 1 つ置く |
| 折れ線 | クリックで頂点を足す。最初の点をクリックで閉じる。Enter / ダブルクリックで確定。Backspace で 1 点戻す | 合間に視点を動かせる |
| 平面モード | Ctrl+ホイール / `[` `]` | 深度を近く / 遠く |
| | F / X Y Z / C | 面に合わせる / 軸平面 / カメラ正対(従来どおり) |

## 5. `uap_stroke_list` の差分

```
{"id":1,"number":"S1","name":"plaza","mode":"surface","shape":"rectangle",
 "pointCount":64,"length":24.1,"closed":true,"area":35.9,"centroid":[x,y,z],
 "bounds":{...},"objects":["Env/Ground"],"samples":[...],
 "contains":{"count":3,"objects":["Props/Bench","Props/Bench (1)","Props/Lamp"]}}
```

`name` は付けたときだけ、`area` / `centroid` は閉じた線だけ、`contains` は閉じた線で
`contents` が真(既定)のときだけ。`contains.objects` は `max_objects` で切り、切れたら
`truncated:true`。開いた線の出力は従来と同じ(`shape` が増えるだけ)。

## 6. エリア分けの想定フロー

1. 表面モード + 矩形(または折れ線)で地面に領域を描く(表面に沿って落ちる)。
   平面モードなら Y キーで水平面にして F で地面の高さに合わせてから描く。
2. S ラベルをクリック(または N)して「広場」「森」と名付ける。塗り色で見分けられる。
3. チップを付けたまま「広場にベンチを 4 つ等間隔で。森の中の木は 1.5 倍に」と頼む。
   エージェントは `uap_stroke_list` で外形・面積・重心・内包オブジェクトを読む。
