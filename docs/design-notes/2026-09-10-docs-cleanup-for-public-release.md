## 1b. 追加依頼(同日): 操作ガイドとインストール URL の表記

- **`docs/USER-GUIDE.md`(操作ガイド)を新設。** README は「何ができるか」の紹介に留め、
  「どう操作するか」は 1 本のガイドにまとめた。画面構成・チャット・チップと添付・権限カード・
  自動承認レベル・質問カード・ツール/サブエージェントカード・履歴・モデル・スラッシュコマンド・
  UapOps・マーカーとピン・リロード共存・設定リファレンス・ショートカット・トラブル対処の 17 節。
  文言は `UiStringsJa.cs` の実際の UI 文字列に合わせ、機能の有無は該当ソース
  (`ContextBarView` のピンボタン、`HistoryRowMenuModel` のメニュー項目、`UapTurnScope` の
  Undo グループ、`AssetLinkHub` のパスリンク化など)で確認した。README(日英)と
  `docs/README.md` からリンク。
- **インストール URL を Markdown リンク表記に変更。** ユーザー指定により、表示テキストは
  タグなしの `...?path=jp.colloid.unity-agent-panel`、リンク先はタグ付き(`#v0.36.0`)とした。
  タグはリンクの href とその直後の説明文の 2 か所に残るので、リリース時の更新箇所は従来通り
  2 か所(`CLAUDE.md` の手順を README.en.md も含む形に更新)。

## 2. 意図的に残したもの

- **`docs/research/` と設計ノートに残る作者環境のパス**(`C:/Unity/UnityProjects/...`、
  サンドボックス名、作者の VRChat アバタープロジェクトの構成調査 `research/04`)。
  実測の記録として価値があり、書き換えると証跡としての意味を失う。`docs/README.md` に
  「作者環境固有の記述で、動作要件ではない」と明記することで対処した。
  `research/04` は作者の私的プロジェクトの内部構成を記述しているため、公開前に削除するか
  どうかは作者の判断に委ねる(本タスクでは触っていない)。
- **`docs/verify/` の XML(約 35 MB)**。設計ノート 39 か所から参照される証跡。
  削除しても Git 履歴からは消えずクローンサイズは減らないため、そのまま残す。
- **テストコード内の `AITemp` / `DevelopmentProject` 文字列**。テストの入力データや
  実測の根拠を示すコメントで、動作には影響しない。
- **README のスクリーンショット**。v0.28 の UI 再設計以前のものが混じるが、差し替えには
  実機が必要なので本タスクの範囲外。

## 3. リリース判断

パッケージのコード・挙動に変更はない。パッケージ内の README と `Documentation~` は
Package Manager に表示されるため CHANGELOG の `[Unreleased]` に `### Changed` として
記録するが、CLAUDE.md の規約「docs/CI のみの変更はリリース不要」に従い、本タスクでは
バージョンを切らない。次のリリースに同梱される。
