# Agent Panel for Unity User Guide

> Site version: <https://agentpanel.futeikei.com/> — the same content with a table of contents and search.

This guide explains the panel that runs coding agents (ACP-compatible CLIs such as Claude Code, Codex and Grok Build) inside the Unity Editor. For installation and requirements, see the [README](../README.en.md).

The guide is split into pages by topic. Open the page you need from the table below. Quoted strings in the text are the panel's English UI text (the UI follows the OS language and can be switched under Settings > Panel > Appearance > "Language").
